## 0. 分析概要

### 缺口鏈路

```
agent（skill 型部署，手上只有 bash）
  └─ 想召回「為什麼改用 pnpm」
       └─ ./cli recall ...                    ← 不存在（src/cli.ts:49-65 無註冊）
       └─ 退路 A：memoria serve + curl        ← 需常駐/管 PID，使用者已排除 service
       └─ 退路 B：寫一次性 node script 呼 SDK  ← 查一句記憶變成寫程式
  └─ 想記下「使用者拍板 X」
       └─ ./cli sync <file>                   ← 需先產出整份 SessionData JSON
  └─ 想回報「剛才那次召回有用」
       └─ （無 CLI 出口）                      ← UFL explicit 訊號在此部署下收不到

core 能力全在（memoria.ts:303 / :273 / :568），缺的只有 CLI 這一層薄殼。
```

### 修法

1. **Phase 1 — 補三個薄殼命令**。全部只做「解析旗標 → 呼叫既有 `MemoriaCore` 方法 → 印出 `MemoriaResult` envelope」，不含任何新邏輯：
   - `recall`：包 `MemoriaCore.recall()`，旗標即 `RecallFilter` 欄位（`src/core/types.ts:204-211`）
   - `remember`：把 CLI 旗標組成 `SessionData` 後包 `MemoriaCore.remember()`；synthetic session 的 id／provenance 寫法沿用 `promoteSummary()`（`src/core/db/git-promote.ts:64` 起）
   - `feedback`：包 `MemoriaCore.recordRecallOutcome()`，補上 UFL explicit 訊號在此部署下唯一的入口
2. **Phase 2 — `brief` 衍生注入面**。把「近期決策 + 高效用記憶 + 活躍 repository 摘要 + 待處理 pending 摘要」編譯成一份 markdown，落在 `<home>/memoria/BRIEF.md`。使用者在 `CLAUDE.md` 以 `@memoria/BRIEF.md` 引入後，每個 session 自動載入，**零執行成本取得近似 hooks 注入的效果**，且完全吃既有分層（SQLite 是事實來源、markdown 是衍生視圖）。

### 不做的事（範圍外）

- **不做 schema 變更**。`--durable`、`--supersedes`、`sensitivity` 等需要落地欄位的能力全數在 [issue-5](../issue-5/README.md)。
- **不新增事件類型**（Q1 建議 (a)）。`remember --type` v1 只映射到既有 `DecisionMade` / `SkillLearned`。
- **不改 `recall()` 行為**。CLI 是新呼叫端，既有 HTTP／SDK／adapter 的召回輸出必須 byte-identical。
- **不自動觸發 `brief`**（Q3 建議 (a)），不在 `sync` 路徑掛副作用。
- **不回頭接 hooks / service**。

## 1. 實作步驟

### Phase 1 — CLI 讀寫回饋三命令

| Task | 產出 | 完成判準 |
|---|---|---|
| 1.1 | `src/cli/commands/recall.ts`：`memoria recall <query>`，旗標 `--project` / `--scope` / `--top-k`（預設 5）/ `--time-window <ISO8601>` / `--mode <keyword\|tree\|hybrid\|vector>` / `--json`。人讀輸出印 `score`、`snippet`、`timestamp`、有 `source` 時附 repository/SHA；`--json` 原樣輸出完整 `MemoriaResult<RecallHit[]>`（含 `meta.recall_id`） | `--json` 輸出與 `POST /v1/recall` 同 body 的回應**逐欄位一致**；未帶旗標時的召回結果與既有 HTTP 呼叫 byte-identical |
| 1.2 | `src/cli/commands/remember.ts`：`memoria remember <text>`，旗標 `--type <decision\|skill>`（預設 `decision`）/ `--project` / `--scope` / `--rationale` / `--json`。組 `SessionData` 後呼叫 `MemoriaCore.remember()`；session id = `note-<sha256(text+type+project) 前 16 碼>`，`INSERT OR IGNORE` 冪等；寫一筆 `memory_sources`（`source_type='cli_note'`，`source_id` = session id）標記來源 | 同一段文字重跑兩次只產生一個 session（冪等）；`./cli recall` 立刻能召回該筆（FTS trigger 生效）；`memory_sources` 有對應 provenance 列 |
